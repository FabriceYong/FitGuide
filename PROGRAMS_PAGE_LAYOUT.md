## Responsive Behavior

### Mobile (< 768px)
```
Hero: Full width, single column
Buttons: Stack vertically or 2-column
Cards: Single column
Filters: Stack vertically
Search: Full width
```

### Tablet (768-1024px)
```
Hero: Full width, buttons in row
Buttons: 3 in row
Cards: 2 columns
Filters: Horizontal wrapping
Search: Full width
```

### Desktop (> 1024px)
```
Hero: Full width
Buttons: 3 in row
Cards: 3 columns
Filters: Horizontal with room
Search: Full width
```

## Animation Sequences

### Section Entrance (800ms)
```
Start:              Mid (400ms):        End (800ms):
Blur(10px)     →    Blur(5px)      →    Blur(0px)
Scale(0.97)    →    Scale(0.99)    →    Scale(1.0)
Y: 30px        →    Y: 15px        →    Y: 0px
Opacity(0)     →    Opacity(0.5)   →    Opacity(1)
```

### Card Cascade
```
Card 1: Start at 0ms
Card 2: Start at 50ms
Card 3: Start at 100ms
Card 4: Start at 150ms
Card 5: Start at 200ms
Card 6: Start at 250ms

Result: Wave effect, not all at once
```

### Hover Animation
```
Button/Card Hover (300ms):
- Border color: white/20 → lime-light/50
- Shadow: subtle → prominent
- Icon scale: 100% → 110%
- Color shift: smooth transition
```
