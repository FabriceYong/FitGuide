## 🚀 How to Start Using It

### Step 1: Install Dependencies (2-3 minutes)
```bash
cd fitguide_nextjs
npm install
```

**Note:** If npm install has network issues, see `NPM_INSTALL_TROUBLESHOOTING.md`

### Step 2: Configure Environment (30 seconds)
```bash
copy .env.example .env.local
```

Edit `.env.local`:
```env
NEXT_PUBLIC_API_URL=http://localhost:5001/api
NEXT_PUBLIC_UNSPLASH_ACCESS_KEY=your_key_here
```

### Step 3: Start Backend API
```bash
cd ../fitguide_api
npm start
```

### Step 4: Start Next.js App
```bash
cd ../fitguide_nextjs
npm run dev
```

### Step 5: Open in Browser
```
http://localhost:3000
```

✅ **Done!** Your Next.js app should be running!
